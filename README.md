# Weather Forecast Predictions
This is a collaboration to complete the second assignment of the **Machine Learning** course at FCAI CU.

## Description
Machine learning models that predict whether it will rain or no using multiple models.

Three models are used to predict the weather:
* Decision Tree
* KNN (K Nearest Neighbors)
* Naïve Bayes

### Here are the main steps to build the models:
1. Loading the [weather_forecast_data.csv](https://github.com/iSeFz/ML_A2/blob/main/weather_forecast_data.csv) dataset.
2. Data analysis, checking for missing values, checking whether numeric features have the same scale.
3. Data preprocessing, separating features and targets, shuffling data and splitting into train and test sets, feature scaling.
4. Implementing Decision Tree, KNN, and Naïve Bayes algorithms using `scikit-learn` library.
5. Implementing custom KNN algorithm from scratch and evaluating its results on the dataset.
6. Reporting and Decision Tree Analysis with detailed explanation.
7. Final report summarizing results of performance of implemented models.
